# 📌 APPENDIX: PRESENTATION TIPS

## Before the Pitch
1. **Know your audience** — Research the officials you're presenting to
2. **Prepare a 2-minute version** — In case time is cut short
3. **Test the demo** — Ensure live demo works offline too
4. **Print backup** — Physical handout with key points

## During the Pitch
1. **Start with the problem** — Make them feel the urgency
2. **Show, don't tell** — Demo the platform for 2-3 minutes
3. **Use local examples** — "In Darbhanga district last monsoon..."
4. **Speak their language** — Reference DRR Roadmap, Sendai Framework
5. **End with clear ask** — "We need partnership, not funding"

## Common Questions to Prepare For

| Question | Answer Approach |
|----------|-----------------|
| "How is this different from 112?" | Complements 112, rural-first, community-powered |
| "What about fake alerts?" | Phone verification, pattern detection, penalty system |
| "Who pays for this?" | Platform is ready, just need partnership |
| "Why should we trust you?" | Show working demo, team credentials |
| "What if internet fails?" | SMS fallback, offline mode demo |

## The One Thing to Remember
> **If they remember nothing else, make sure they remember:**
> 
> *"Bihar Sahayata reduces emergency response from 4 hours to 20 minutes. 
> That's the difference between life and death."*
